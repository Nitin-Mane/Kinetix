# Changelog

All notable changes to Kinetix should be documented here.

The project should follow semantic versioning after the first stable release. Before 1.0, minor releases may contain breaking changes, but every breaking change must include migration notes.

## Unreleased

### Added

- Initial language charter.
- Complete roadmap.
- Draft grammar.
- Compiler, interoperability, ROS 2, performance, testing, and governance design documents.

### Changed

- Adopted `.kx` instead of `.kt`.
- Adopted Kinetix/KX instead of K++ as the official name.

### Rejected

- Separate runtime numeric types for binary, octal, decimal, and hexadecimal notation.
- Universal “faster than C++” claim.
